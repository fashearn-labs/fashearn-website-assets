## Mandatory continuation rule

Before substantive changes, review this file, the current repository state, and relevant repository notes.

Do not remove, simplify, rename, omit or redesign established functionality merely because a new chat/session starts. Inspect the current source, make the smallest safe change, test against the existing baseline, and record significant changes in GitHub.
